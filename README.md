# IT6203 Lab 2 — TypeScript and JSON

## Overview

This project demonstrates the use of TypeScript and JSON as required by the IT6203 module.

The project demonstrates:

- TypeScript variables and type annotations
- Functions
- Arrays
- Interfaces
- Classes
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- JSON data
- TypeScript and JSON integration
- TypeScript compilation
- Console execution
- Browser execution

## Technologies

- Node.js
- npm
- TypeScript
- HTML
- JSON
- http-server
